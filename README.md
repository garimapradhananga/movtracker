🎬 MovTracker
A personal movie tracking web app built with Flask, SQLite and TMDB API.

Live demo: https://movietracker-guzz.onrender.com

## Features
- Search movies powered by TMDB API
- Track movies as Watched, Watching or Want to Watch
- Rate movies out of 10
- Filter by status and genre
- Personalized recommendations based on watched movies
- Stats page with your watching summary
